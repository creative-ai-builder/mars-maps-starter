The Idea
READ THIS FIRST

When you give AI a big ask — like "build me a dice roller with animation and sound and a score counter" — one of two things happens:

  • It takes 10 minutes and comes back half-wrong
  • It does three of the four things and forgets the rest

Small prompts beat big prompts — every time. One ask → AI finishes fast → you check → you ask the next thing. You stay in control.

The three-column trick:

What I want → Small asks → Order to send them

"A dice roller" →
1. Show a random number 1–6 when the page loads
2. Add a Roll button that changes the number
3. Make the number animate when it changes
4. Add a total counter below the dice

Each step is one clear ask. You can verify each one works before sending the next.
