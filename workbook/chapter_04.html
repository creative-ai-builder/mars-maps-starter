The Idea
READ THIS FIRST

AI makes stuff up. It does it confidently. It does it in a calm voice. And it does it all the time.

This is called a hallucination — when AI states something false as if it were true. It's not lying on purpose. It just doesn't know what it doesn't know.

Three warning signs:

  • Confident and specific: "The function is called getMapCoords()" — sounds authoritative, might be invented
  • The same fix three times: AI keeps trying the same thing and it keeps not working
  • Can't be verified easily: AI says something that would take you hours to check
The fix: verify before you accept.

• Check MDN (developer.mozilla.org) for any JavaScript fact
• Open browser DevTools console and test it yourself
• Ask AI: "Are you sure? Can you show me a source?"
• Try a tiny test snippet instead of the full feature

You're the editor. AI is the first draft. First drafts have mistakes.
