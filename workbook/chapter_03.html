The Idea
READ THIS FIRST

You can have a small prompt that still goes wrong. Why? Because you didn't say how you'd know it was done correctly.

Professionals call this acceptance criteria — the exact conditions that make something "done."

  • Units: km or miles? Celsius or Fahrenheit? 2 decimal places or 4?
  • Position: top-left corner? centered? 16px from the edge?
  • Trigger: on keypress? on button click? on page load?
  • Edge cases: what happens if the input is empty? negative? a letter?
❌ "Show the answer rounded off"

✅ "Display the result rounded to 2 decimal places in a bold span directly below the input, updating live as the user types"

The second prompt answers: how many decimals, where it goes, and when it updates. No guessing.
